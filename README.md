# A Neovim Tool for Pi

<p align="center">
  <a href="https://pi.dev">
    <img alt="pi logo" src="https://pi.dev/logo-auto.svg" width="128">
  </a>
</p>

> A Pi extension providing a __`discover_neovim`__ Tool for __[Pi](https://pi.dev)__ to find __[Neovim](https://neovim.io)__ instances, and select which one to interact with (using [Neovim's RPC API](https://neovim.io/doc/user/api) through tools such as [pi-msgpack-rpc](https://github.com/paperlib/pi-msgpack-rpc).)
